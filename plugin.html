PUBLIC REVIEW WORKFLOW

Bridge Review Panel

An independent second-opinion workflow for plans, drafts, code, architecture, and attached project files. It is intentionally narrower than the private AI Bridge workspace.

Independent review • structured synthesis
What it does

For a user-requested review, the service sends only task-specific content to authorized external AI APIs, obtains independent assessments, and returns a structured synthesis plus the independent reviews. The public plugin does not expose provider selection or single-provider passthrough tools.

Public plugin tools

  • Review a task or plan
  • Review code or architecture
  • Review attached text/code/ZIP project files
  • Check panel availability

Data boundaries

Do not submit passwords, API keys, payment-card data, protected health information, government identifiers, MFA codes, or other restricted data. See the Privacy Policy for processing details.
