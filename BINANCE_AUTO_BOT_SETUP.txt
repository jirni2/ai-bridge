AI BRIDGE BINANCE AUTO BOT — EXACT DEPLOYMENT

Two Cloudflare components are required. Cloudflare Pages cannot deploy a Durable Object class inside a Pages project. This is a stateful trading Worker, not Cloudflare Workers AI.

1. Deploy the Worker at binance-bot/worker.mjs using binance-bot/wrangler.toml (script name aibridge-binance-bot). Example from the binance-bot directory: npx wrangler deploy. This creates the SQLite-backed BinanceBot Durable Object migration v1. The public Worker route returns 404.
2. Add BINANCE_TESTNET_API_KEY and BINANCE_TESTNET_API_SECRET as encrypted secrets to the aibridge-binance-bot Worker, not to Pages, the ZIP, browser localStorage or chat. Generate these in Binance Spot Testnet with only needed trade/account permissions. Never enable withdrawals.
3. In Cloudflare Pages project aibridge, Settings > Bindings > Add > Durable Object. Variable name: TRADE_BOT. Worker: aibridge-binance-bot. Class: BinanceBot. Bind production and preview intentionally as separate environments if desired.
4. Deploy the entire AI Bridge Pages ZIP. Check /api/trade/bot (requires the Bridge session) and open /trade/. Click Verify Binance API, then Start Auto in Testnet. Check actual Binance Spot Testnet orders and the journal after a candle signal; verify operation after closing the phone tab.
5. Leave live disabled until testnet has been exercised with real credentials, reconnection, exchange rejection, partial/unknown fills, and observed order reconciliations. To enable live intentionally: create separate restricted live trade-only key pair as Worker secrets BINANCE_LIVE_API_KEY and BINANCE_LIVE_API_SECRET. Set BINANCE_LIVE_ENABLED=1 in the Worker, deploy, and type LIVE in the UI at start. The code caps a BUY at 10 USDT and total daily buys at 20% of a 50–100 USDT budget. Disable withdrawals and apply Binance IP allowlisting where the hosting egress arrangement permits it. Never reuse the Bridge token or AI provider tokens as trading keys.

Operational cautions: Pause/Stop prevents new orders but does not sell an open position. Polling is every ~60 s and is not an exchange-side stop order; rapid price gaps can exceed 3% loss. Exchange fees and price slippage affect actual P/L, while the UI day P/L is approximate. An ambiguous order is retained for reconciliation and can stop new trading. Testnet can reset balances and orders. Do not claim a live guarantee or profit forecast. A real live deployment needs independent review and an actual observed testnet cycle before activation.
