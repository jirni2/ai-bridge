Bridge Review Panel Privacy Policy

Clear boundaries for what the public review workflow processes, where content may go, and what the private AI Bridge web app stores locally.

Effective September 30, 2026

Data we process

When you explicitly invoke a review tool, we process the task text you choose to send and, for file review, readable text/code extracted from the attached files you select. We do not ask for full conversation history, precise location, advertising identifiers, or account passwords.

Purpose

We use this content only to obtain independent assessments and return a second-opinion review to you.

Recipients

Review content may be sent to authorized third-party AI API processors used by the public review workflow, currently Google Gemini API, Groq API, and OpenRouter. Only the minimum task-specific content needed for the requested review is sent. The plugin does not intentionally send your Bridge password or provider API keys to those services.

Retention

The Bridge Review Panel application layer does not intentionally write review task contents or attached-file contents to persistent application storage. Content is held in request memory only while the review is being processed, normally for less than two minutes, and is then discarded by the application layer. Cloudflare and the external API processors may retain operational or API data under their own service terms and policies; those systems are outside our direct control.

Private AI Bridge web app

This policy primarily describes the public Bridge Review Panel plugin. The owner-only AI Bridge web app is a separate private workflow: it may keep local browser history in IndexedDB, a small resumable-job marker in localStorage, HttpOnly authentication/provider-token cookies, and short-lived resumable job records in configured Cloudflare storage. If the owner turns on “Sync history between devices”, recent task history (text only, no attachment data) is also stored in the owner’s own Cloudflare KV namespace; it is off by default and “Clear” removes it. Per-provider usage counters are kept only in the browser. If the owner configures Cloudflare AI Gateway, provider requests pass through the owner’s own gateway, where Cloudflare logs them according to the owner’s gateway settings. When you explicitly attach a photo and press Send, the private app may transmit the resized image together with your task to a configured vision-capable AI provider (Gemini, OpenAI, Claude, or Grok). Camera/photo selection stays local until Send. Browser speech recognition, when available, writes recognized text into the task field and does not auto-send it. Those private-app mechanisms are not used to create an advertising profile or sell user data.

Optional exchange connection (private app only)

The owner-only AI Bridge web app may include an optional trading module that the owner can connect to a cryptocurrency exchange account. It is not part of the public Review Panel. When the owner enables it, requests are sent to the exchange the owner configures, using API keys the owner supplies in their own Cloudflare settings; that exchange’s own privacy policy and terms apply to those requests. Exchange keys, wallet seed phrases and passwords must never be pasted into chat tasks or support messages.

Restricted and sensitive data

Do not use the plugin to submit payment-card information, protected health information, government identifiers, passwords, API keys, MFA/OTP codes, or other authentication secrets. If such information appears in a project file, remove it before requesting review.

Your controls

You control whether to invoke the plugin and which text or files to send. You can cancel before invoking a review, omit attachments, or remove sensitive material from files. For privacy questions, use the support page.

Sale and advertising

We do not sell review content and the plugin does not serve advertising.

Contact

Privacy and support questions can be sent to aibridge.support@gmail.com.

Changes

If this policy changes materially, the published policy will be updated before the affected plugin workflow is offered under the new terms.
