# AI Bridge — правила роботи

- Власниця не програмістка: звіти українською, простими словами, коротко.
- Сайт: Cloudflare Pages, проєкт `aibridge-aff`, https://aibridge-aff.pages.dev
- Публікація — лише через GitHub Actions (`.github/workflows/deploy.yml`):
  `main` = основний сайт, будь-яка інша гілка = пробне посилання
  `https://<гілка>.aibridge-aff.pages.dev`.
- Кожне покращення — в окремій гілці: тести → пробне посилання → короткий звіт.
  У `main` зливати тільки після явного «так» від власниці.
- Перед комітом: `node tools/run-all-tests.mjs` (усі файли PASS),
  оновити версію (`tools/sync-version.mjs`, `tools/fingerprint-build.mjs`), STATUS.md і CHANGELOG.
- Секрети (ключі, токени) ніколи не потрапляють у репозиторій чи чат.
- Залізне правило Ядра: текст питання користувача Ядро в хмару не надсилає.
- Напрям розвитку: самостійніше Ядро (`core.js`); наступний великий крок —
  мала мовна модель у браузері як запасний рівень після правил Ядра.
- Торговий модуль (`trade/`, `binance-bot/`) без окремого прохання не чіпати.
