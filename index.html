      ПРІОРИТЕТИ МАРШРУТИЗАЦІЇ
      BACKGROUND TASKS
      Фонова модель

      Дешева швидка модель для службових задач: оцінки Judge й фонові виклики. Преміум-моделі — лише для відповідей.

      Моделі команди

      для Ask All / Code / Debate
      Single AI: вибери одну модель. Запит піде тільки їй — без тихої підміни іншою.
      Agent: сам планує до 4 кроків, може шукати в інтернеті, читати публічні HTTPS-сторінки та делегувати іншим AI. Зовнішні дії не виконує без окремого інструмента.
      God Mode: максимальний контрольований режим — веб, Agent, незалежна перевірка і навчання на результатах.
      Як працює Auto

      Auto працює reliability-first: для звичайного чату Bridge паралельно пробує пріоритетні free‑провайдери, бере першу справну відповідь і скасовує повільнішу. Для Code Review / Ask All / Debate / файлів залишаються багатомодельні режими. Платний OpenAI, Claude або Grok використовується як fallback лише якщо ти сам його вибрав, або якщо free‑провайдери взагалі не налаштовані.

      SELF-LEARNING

      Навчання і самовдосконалення

      AI Bridge вчиться на кожному результаті: які маршрути та моделі працюють найкраще, які падають, що тобі подобається. Поведінка підлаштовується автоматично, а зміни коду лише пропонуються і проходять тести.

      1Відповідь
      →
      2Твоя оцінка + перевірка
      →
      3Авто-адаптація маршрутів
      →
      4Пропозиції коду + тести

      Автоматично: порядок моделей, вибір маршруту, стиль відповідей. Тільки з твого дозволу: зміни в коді — через node tools/improvement-lab.mjs, який запускає всі тести.

      Перевіряю готовність…
      Як додати в ChatGPT

      1. Відкрий ChatGPT у вебверсії → Settings → Apps → Advanced Settings і увімкни Developer mode. Для Business це також доступно через Workspace Settings → Apps → Create.

      2. Відкрий Settings / Workspace Settings → Apps → Create, встав MCP URL вище та вибери OAuth.

      3. Натисни Scan tools. Коли відкриється AI Bridge Login, введи свій BRIDGE_ACCESS_TOKEN і заверши авторизацію.

      4. Після сканування створи app. ChatGPT має побачити: Review task, Review code, Review attached project files та Review panel status.

      5. Важливо: повна підтримка custom MCP apps зараз доступна для Business та Enterprise/Edu у вебверсії ChatGPT; Pro може підключати MCP з read/fetch у developer mode. На Plus AI Bridge працює як окремий веб‑додаток, але цей custom MCP connector підключити не можна.

      AI‑провайдери з телефону

      Встав token прямо тут і натисни Зберегти. AI Bridge шифрує його на сервері та зберігає у HttpOnly Secure cookie цього пристрою. Token назад у сторінку не повертається.
