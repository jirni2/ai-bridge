AI Bridge v4.9.0

- Fixed iPhone/Safari `Load failed` during long ZIP/file audits by adding `/api/run-stream` with NDJSON heartbeat events.
- Main Chat/Files execution now keeps the HTTP connection active while reviewers and Judge are working.
- Added automatic fallback to legacy `/api/run` only when the streaming endpoint cannot start, avoiding duplicate AI work after a stream has begun.
- Replaced raw Safari `Load failed` / `Failed to fetch` text with actionable Ukrainian network errors.
- Added streamed request IDs and progress heartbeats for production diagnostics.
- Added regression coverage proving the stream starts before the provider finishes and returns the final model result.
