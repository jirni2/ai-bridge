PACKAGING INTEGRITY REPAIR
--------------------------
A post-build comparison against the actual v4.9.3 deployment ZIP found that
21 files had been omitted from the first v4.9.4 archive even though v4.9.4 is
described as behavior-identical to v4.9.3. The corrected deployment artifact
restores those files from the verified v4.9.3 package.

Deployment-critical restored files include:
- icon-180.png
- icon-192.png
- plugin.html
- oauth-replay-do.js
- SUBMISSION_CHECKLIST.txt

Why this matters:
- index.html references icon-180.png.
- manifest.webmanifest references icon-192.png.
- sw.js pre-caches icon-180.png and icon-192.png with cache.addAll(); missing
  assets can reject the service-worker install promise.
- support/plugin links expect the public plugin information page.
- OAUTH_REPLAY_DO_SETUP.txt explicitly requires oauth-replay-do.js for the
  separate replay-guard Worker used by public plugin mode.

All other files that existed in the verified v4.9.3 deployment package were
also restored so that the v4.9.4 package is a true packaging superset of
v4.9.3 plus the intended version/fingerprint updates and this changelog.
